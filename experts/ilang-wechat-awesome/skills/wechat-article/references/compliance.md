# 公众号合规：脱敏表、敏感词、红线

微信违禁词库是动态的、不公开的。原则三条：能不提就不提；必须提就用安全替代词；写完默读一遍，想象自己是微信审核员，会不会标记这篇。

## 品牌脱敏表（微信内写法）

| 全称 | 微信内写法 | 说明 |
|---|---|---|
| Claude | A 社 | 必须脱敏 |
| Claude Code | CC、网页版 CC | 必须脱敏 |
| Opus | Opus4.6 | 加版本号反而安全，像技术术语 |
| OpenAI | O 社 | 必须脱敏 |
| Google | G 社 | 看情况，"谷歌"一般可用 |
| GPT | GPT | 可以直接写 |
| Telegram | 电报 | 微信违禁词 |
| WhatsApp、Line、Signal、Discord | 海外聊天工具 | 或直接不提 |
| Facebook | 脸书、海外社交平台 | |
| Twitter、X | 海外社交平台 | 单独写 X 容易被误判 |
| Instagram | Ins、海外图片社交 | |
| YouTube | 油管、海外视频平台 | |
| TikTok | 抖音国际版 | 涉及数据安全话题时更敏感 |
| Reddit | 海外论坛 | |

X、HN、Reddit 平台的文章不需要脱敏，全名直写。

## 零容忍（一个字都不写，没有替代词）

VPN、翻墙、科学上网、梯子、代理、机场、节点、订阅链接、Shadowrocket、V2Ray、Clash、sing-box、SSR、SS、VLESS、VMess、Trojan、GFW、防火墙、墙（指网络审查时）。

话题必须涉及网络访问时，用"网络环境""跨境网络""懂的都懂"这类模糊表达，但最好的策略是换一个角度，根本不碰这个区域。

## 不碰的类别

| 类别 | 规则 |
|---|---|
| 政治 | 领导人姓名、敏感历史事件、敏感组织、台港藏疆、特定语境下的清零、润、躺平。公众号是商业平台，政治观点等于风险零收益 |
| 赌博色情暴力 | 赌场、博彩、下注、赔率、菠菜、约炮、裸聊、成人内容、恐袭细节 |
| 金融加密 | 可以科普区块链技术，不能写教程或推荐购买；ICO、发币、炒币涉嫌非法集资宣传 |
| 医疗药品 | 可以讲健康知识，不能给具体用药建议或带货；处方药名加购买渠道、未经批准的疗法、减肥药壮阳药推荐 |

## 平台红线（算法层面）

| 红线 | 后果 |
|---|---|
| 正文放 URL | 限流，外链放"阅读原文" |
| 放个人微信号 | 互动导流违规 |
| 价格和联系方式组合出现 | 判定引导线上交易 |
| 整篇文章是销售页 | 封禁，框架必须是经验分享 |
| 引导点赞、转发、收藏、关注、利诱 | 违规删文扣信用分，可能限流封号 |
| 刷量互阅互赞 | 新号杀手 |
| 标题党 | 高点击低完读等于反扣分 |
| 搬运洗稿 | 不进推荐池 |
| 批量 AI 水文 | 系统能检测，探索预算永久回收 |
| 被毙文章原文重发 | 有指纹，换号也能识别 |

惩罚不是删文那么简单，是移入低信任桶，曝光骤降，恢复极慢。惩罚恢复比 5:1 到 10:1，一次违规要 5 到 10 篇好内容才能爬回来。

## 一次真实的导流事故

2026 年 6 月，一篇培训课介绍文章因"导流内容"被微信封禁。触发项三个：文章里写"加微信 XXXXXXX"；价格和联系方式组合；整篇是销售页。

修法：联系方式改成"后台回复'培训'两个字即可"；价格可以写；框架从销售页改为经验分享；标题去掉"价格写明白"这类暗示销售的措辞。

## 敏感内容的处理

- 被平台毙过的文章不在公众号原文重发
- 灰产、逆向、具体攻击方法只在自有网站或付费社群发；公众号站"科普、法律警示、自我保护"的角度
- 被举报和被算法毙不一样：算法毙换号碰运气，人举报内容本身要改，换号也会被毙
