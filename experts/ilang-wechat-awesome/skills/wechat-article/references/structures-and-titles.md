# 骨架、标题、开头、钩子、结尾、破圈版

## 两种骨架，提纲阶段二选一

**六段式（观点文、现象文）**

| 段 | 内容 | 要求 |
|---|---|---|
| 引子 | 一个具体的事件、评论、现象、数据 | 开头必须是一个能让人停下来的信息：数据、冲突、反常识 |
| 拆穿 | 2 到 3 段，这个现象为什么存在，背后逻辑 | 讲清利益链、信息差、认知差 |
| 众生相 | 把行业里的人分成 3 到 5 类，每类一段 | 用表格或分类列举，读者要的是对号入座 |
| 我的做法 | 1 到 2 段，直接说自己怎么做，不解释为什么 | "就是这样的"比"因为我觉得"有力；行业规则里可以夹私货 |
| 故事或私货 | 1 到 2 段，个人经历、细节、场景感 | 放开写，讲故事比推销有信任感；可加场景落款 |
| 收尾 | 一句话 | 短、狠、不解释，回扣标题 |

**八区块（项目复盘文、赚钱案例文）**

| 区块 | 内容 | 要求 |
|---|---|---|
| 开头（前 150 字） | 证据先行，截图或数据，加一句话解释 | 不铺垫不自我介绍 |
| 1 项目背景 | 100 字以内 | 用类比讲清楚 |
| 2 项目逻辑 | 一段话加一张流程图或表格 | |
| 3 真实数据 | 后台截图位加关键数字标注 | |
| 4 过程记录 | 从亏到赚的弧线 | 有失败才真实 |
| 5 阶段复盘 | 诚实讲什么做对了什么做错了 | 带具体数字 |
| 6 成本、人员、工具 | 可复制感 | 读者觉得"我也能做" |
| 7 当前状态加下一步 | 情绪高点收尾 | 留追更钩子 |
| 收尾 | 疑问句引评论加署名 | |

## 标题四种公式（25 字以内，含具体数字）

| 类型 | 公式 | 示例 |
|---|---|---|
| 数据型 | 人数 + 时间 + 反常识 + 结果数字 | "2 个人，一个月，不靠 AI，10w 刀" |
| 反差型 | 身份反差 + 动作 + 结果 | "营销分析师，不会代码，3 周做出月入 20 万美金的网站" |
| 否定型 | 否定常识 + 证据 + 结论 | "90% 的人选错品类，同样 100 次点击收入差 20 倍" |
| 痛点型 | 痛点 + 解决 + 数字 | "申请 AdSense 被拒 3 次？用这个工具一次查出所有问题" |

逗号切割法：标题切成 3 到 4 个信息弹片，每个都是独立钩子。例："1 个人，4 个月，零基础，月入万刀是目标"。

差标题："SEO 技巧分享"（无收益）、"关于 AI 的一些思考"（无钩子）、"震惊！太厉害了"（标题党）。标题党是自杀行为：高点击率加低完读率，系统判定欺骗点击，直接停止推荐。

标题直白有冲击力，公众号主标题少用疑问句，反问留给正文和结尾。

## 前 150 字（生死线）

种子池用户对你零忠诚度。前两段像水文，秒退，系统收回预算。

必须有：这篇解决什么问题（一句话）、读完能得到什么（具体承诺）。证据先行：截图、数据先上，一句话解释。

绝对不写：人生感悟开头、"最近我在想一个问题"、故弄玄虚的铺垫、三段废话之后才进正题。

## 中段

每 300 到 400 字一个视觉锚点（表格、截图位、代码块交替），连续 5 段没有视觉变化等于完读率杀手。长文（超过 2000 字）在 40% 到 60% 的位置插一句中段钩子："下面这张表是全文最值钱的""最后 3 个是我自己在用的"。

## 结尾

一句话回扣标题形成闭环，说完就走。互动引导只做一件事：引评论，用疑问句。"评论区聊聊，你现在在用哪个？""你踩过最大的坑是什么？"

绝对不做："觉得有用点个赞""转发给你的朋友""点赞收藏转发三连"。

## 破圈版（用户要时才给）

同一篇干货，两套标题、两套开头，核心正文复用 80%。破圈版做前端引流，干货版留给铁粉。改的不是你在写什么，是读者第一眼看到的是什么。

| 类型 | 核心 | 入口宽度 | 漏斗位置 |
|---|---|---|---|
| 身份共鸣型 | 标题给出具体身份处境，读者一眼代入 | 最宽 | 顶部 |
| 故事型 | 挫折、尝试、发现、验证、方法公开 | 宽 | 中部 |
| 观点型 | 否定型观点引发争论，两方都给算法正向信号 | 中 | 中下 |
| 信任型（干货） | 深度内容建立专业信任 | 窄 | 底部 |
| 转化型（案例） | 软性引导到产品或课程 | 最窄 | 最后 |

示例：窄入口"Amazon 联盟谷歌 Ads 搜索套利"只有懂投放的人会点；宽入口"不用囤货不用发货不用客服，靠投广告拿佣金"任何想搞副业的人都会点。

节奏：每周 3 篇是 1 破圈、1 信任、1 转化；每周 2 篇是两周里 1 破圈、2 信任、1 转化。
