你投喂素材，它按 200 多篇实战文章验证过的写作基因帮你重组成公众号文章。

## 一句话说清楚

作者 200 多篇实战文章背后的结构规律，提取成写作基因装进一个专家。你投喂素材，它帮你重组结构、出 3 个标题、出 MD 正文、生成封面图提示词、内置去 AI 味，12 项自查全绿才交稿。

（背景数据：这批文章在作者自有账号的分享率 8 到 15%，行业爆款线 3%。仅作方法论出处说明，不构成对你文章效果的承诺。）

## 输入 → 输出

```
你的素材（文章 / 数据 / 笔记 / 本地文件）
         ↓
   iLang 公众号写作助手
         ↓
  1. 3 个标题（各标公式类型）
  2. MD 正文（带日期存成新文件）
  3. 封面图提示词（丢给 AI 出图工具）
  4. 自查报告（12 项全绿才输出）
  5. 一句发布建议
  6. 你说「推草稿箱」：转微信 HTML，传图传封面，推进草稿箱，回读核对（只到草稿箱）
```

## 不是什么

这不是"帮我写一篇爆文"的生成器。你不带素材来，它直接拒绝你，并告诉你素材从哪来。

你得自己找素材、自己定角度、自己补个人经历和语气词。专家只负责结构和规范：不编数字、不编经历、不硬塞口语。

## 2.0 比 1.2 多了什么

| 项 | 1.2 | 2.0 |
|---|---|---|
| 写作基因 | 17 条 | 23 条，加了标题、前 150 字、视觉锚点、独家内容、骨架选择、破圈版 |
| 去 AI 味 | 推荐另装 DeAI 专家 | 内置 deAI 三件套，一个专家搞定 |
| 骨架 | 六段式 | 六段式加八区块复盘式，提纲阶段二选一 |
| 合规 | 7 条红线加 6 个品牌简称 | 脱敏表 14 项、翻墙类零容忍、四类不碰话题、一次真实封禁事故的修法 |
| 算法 | 无 | 完读率档、信号权重、发布节奏、发帖时间 |
| 排版 | 只给 ilang.cn/md | 加转微信 HTML 规则和接口推草稿步骤、踩坑清单 |
| 多平台 | 无 | X、HN、Reddit 速查，一稿多发的起点 |
| 协议 | I-Lang v4.0 头 | iLang v5.0 头加 IML 0.5 工作链 |
| 推草稿箱（2.1 新增） | 无 | 技能 wechat-draft-push：官方接口推进草稿箱并回读，个人主体账号也能用，没有发布命令 |
