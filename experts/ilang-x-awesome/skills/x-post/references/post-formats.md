# 三种格式

## 单帖

- 280 加权字符内。中日韩每字算 2，所以中文帖大约 140 个字到顶；英文字母、数字、标点算 1；任何链接按 23 算；emoji 算 2。
- 脚本 `gate` 算的是近似值，官方按 Unicode 区间细分，边界差一两个字不影响；超了编辑框会标红。
- 结构：第一行说事，中间一到三句展开，最后一行问题或争议点。

## 串帖

- 文件里用单独一行的 `---` 分条，脚本 `thread` 按顺序发并串起来，`intent --thread` 则一条一个编辑框。
- 第一条是钩子：说清这串讲什么、读完得到什么。第一条就讲细节没人展开。
- 中间每条一个完整观点，单独拿出来也成立。
- 最后一条收口：回扣第一条，放那个具体问题。
- 条数由内容定，一般 4 到 8 条，不凑数。
- 每条都过 280，每条都记日志。走接口时中间一条失败脚本会停下来报到第几条，已发的不会撤。

## 长文

- 只在作者有独家材料时写，没有就写串帖。
- 结构：前 150 字说清结论，中段一个钩子，结尾回扣开头。
- 接口发不了长文，写好交给用户手动贴。脚本不假装能发。

## 配图

- v1 不做自动配图。用户有图自己传，没图就纯文字。
- 不接任何出图接口。
