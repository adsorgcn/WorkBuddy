# X 写作规则（开放层，七条加三条）

## 七条

1. 钩子开头。前两行决定有没有人展开，第一行直接说事：一个具体数字、一件具体事、一句反常识的话。
2. 短句。一句一个意思。手机上一行 20 个字左右，三行以上的句子没人读。
3. 一条帖一个点。单帖约 100 到 140 汉字，280 加权字符内（中日韩每字算 2，链接算 23）。放不下拆串帖，不压成长句。
4. 对标文的文字按 X 的写法重切，不整段贴；观点、数据、图、视频可以直接拿。至少一句是作者的判断，没有判断就不发。
5. 不确定的数据标「待确认」，让作者核。不编数字、不编引语、不编经历。
6. 结尾一个具体问题或一个争议点，具体到别人能用一句话答。「你怎么看」太空。不喊点赞转发关注。
7. 口吻直接、干货、带判断。第一人称，说结论不说过程，过程放串帖后面几条。别找补，自嘲可以，自夸不行。

## 反 AI 三条

- 禁长破折号，用逗号或句号。
- 禁结构化标题：「要点如下」「总结一下」「Key takeaways」这类不写。
- 禁口癖词：delve、tapestry、landscape、arguably、it's worth noting、reimagine、值得注意的是、让我们、总而言之、首先其次最后。

另外两个指纹：排比三连，每段一样长。打乱句长，一段长一段短。

## 实体怎么写

中文帖里提到海外公司、产品、人，给 @handle（用户给的）或写英文名，不写中文译名让人猜。英文帖里中文实体同理反过来。

## 写完自查（专家会自己过，这里给人看）

- 长破折号 0
- 口癖词 0
- 加权长度单帖 280 内，串帖每条 280 内
- 结尾有具体问题或争议点
- 数字有来源或标了待确认
- 正文链接 0
- 禁区话题 0
- 和最近发过的不相同不相似
