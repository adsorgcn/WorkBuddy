# 数据源

## X榜单 MCP（第一源，用户自己买）

- 是什么：xbangdan.com 是 X 中文区的数据门户，首页有发帖、评论、涨粉、曝光的榜单，24 小时最火推文，话题榜，长文榜，黑马榜，海外榜。它的 MCP 把这些数据接进任何支持 MCP 的 AI 工具（Claude Code、Codex、Cursor、Cherry Studio 这类；网页版聊天工具加不了）。
- 价格：999 元一年，每天 300 次查询，做一份早报一般十几次。从兑换那天起算。
- 开通三步：到 xbangdan.com/mcp 按页面说明购买拿卡密（XBD 开头）→ 回到页面兑换，拿到密钥和一行配置（完整密钥只显示一次，同一张卡密可以再兑换一次，旧密钥作废）→ 把那行命令粘进自己的 AI 工具，重开后看到 xbangdan 已连接就通了。
- 能力：查爆款（近 30 天曝光 5000 以上的推文，按天数、关键词、赛道、内容类型、图视频、作者粉丝数筛，按曝光、点赞、收藏排，能拿全文和配图）、查账号（7 天、30 天涨粉，发帖频率，最火几条；只查收录了的号）、看热点（今天中文区热聊话题，每个两条代表推文）。
- 只读，不碰用户的 X 账号。密钥在用户自己的 MCP 配置里，本技能不接收。
- 没收录的号：先在首页提交，或者拿同赛道对标号先研究。

## 仓库每日清单（第二源，免费）

- 文件：仓库 `data/hot/latest.json`，每天早上自动更新。字段：`date`、`groups`（AI、科技、热榜、财经、产品、海外、热搜词，每组按新到旧）、`hot_now`（多平台同聊的）。每条有 `title`、`url`、`source`、`lang`、`published`、`platforms`、`members`。
- 脚本：`scripts/x_feed.py`。在仓库克隆里跑读本地，不在就从 GitHub raw 拉；国内网络拉不到就只能用 X榜单或用户自己给素材。
- 过滤顺序：禁区初筛 → 时效 → 语言 → 关键词 → 和本机发过的去重。排序：多平台同聊的在前，再按新旧。

## 用户自己的素材（第三源）

他自己的经历、数据、实验、踩过的坑。这是独家，权重最高，有就优先。
