# 数据源

## X榜单 公开榜（第一源，免费）

- 是什么：xbangdan.com 是 X 中文区的数据门户。首页有发帖、评论、涨粉、曝光四个冠军榜，24 小时最火推文，话题榜，长文榜，黑马榜，海外榜，精选副业专栏。页面是服务端渲染的 HTML，不用登录、不用 MCP，脚本 `scripts/x_rank.py` 直接解析，Agent 自己打开页面读也一样。
- 四个能解析的页面：`/posts/` 24 小时最火推文（每小时曝光、作者、赞数、发了几小时）；`/words/` 话题榜（帖数、人数、首发时间、曝光、升温或退烧，每个话题带一句摘要）；`/articles/` 长文榜（近 7 天按收藏排，分中文区和海外区，带分类和曝光）；`/global/` 海外榜（点赞、曝光、转发、收藏）。
- 对标账号页：`/account/<handle>/`。
- 页面每天早上定格、白天持续刷新。脚本一次跑四个页面四个请求，别一分钟跑几十次。

## X榜单 MCP（可选，用户自己买）

- 999 元一年，每天 300 次查询，近 30 天 11 万+ 条曝光 5000 以上的推文，每小时更新，只读不碰用户的 X 账号。
- 比公开榜多的：按天数、关键词、赛道、内容类型、有没有图视频、作者粉丝数在 30 天库里筛；看中的能拿全文和配图；查账号 7 天、30 天涨粉和发帖频率（只查收录了的号）。
- 开通：到 xbangdan.com/mcp 按页面说明买卡密（XBD 开头）→ 页面兑换拿密钥和一行配置（完整密钥只显示一次）→ 粘进 Claude Code / Codex / Cursor，`/mcp` 看到 xbangdan 已连接。网页版聊天工具加不了。
- 密钥在用户自己的 MCP 配置里，本技能不接收。用户没装不劝他买，公开榜已经够选题。

## 仓库每日清单（兜底，免费）

- 文件：仓库 `data/hot/latest.json`，每天早上自动更新。字段：`date`、`groups`（AI、科技、热榜、财经、产品、海外、热搜词，每组按新到旧）、`hot_now`（多平台同聊的）。每条有 `title`、`url`、`source`、`lang`、`published`、`platforms`、`members`。
- 脚本：`scripts/x_feed.py`。在仓库克隆里跑读本地，不在就从 GitHub raw 拉；国内网络拉不到就只用 X榜单或用户自己给素材。
- 过滤顺序：禁区初筛 → 时效（按北京时间）→ 语言 → 关键词 → 和本机发过的去重。排序：多平台同聊的在前，再按新旧。

## 中国大陆自媒体（对标文的来源）

X榜单 回答「今天什么热、什么形态在爆」，对标文回答「这个题最硬的内容在哪」。大陆自媒体写得透的东西 X 中文区大多没见过，这就是信息差，顺序：

- 公众号：装了公众号选题技能 wechat-topic-hunter 的，用它的 `search --keyword` 搜文章、看阅读数（用户自己的 wxrank key）；没装的用搜狗微信搜索 https://weixin.sogou.com/ 搜标题关键词，Agent 自己打开。
- 知乎、B 站、头条：Agent 自己搜，知乎看高赞回答，B 站看播放和弹幕量。
- 抖音、小红书：Agent 自己开页面看，图和短视频多。
- 仓库清单：`data/hot/latest.json` 每条的 `members` 里有各平台的原文链接。

对标文要存四样：标题和链接、正文要点、图片地址、视频地址。交给 x-post 时一起给。

## 用户自己的素材（最高优先）

他自己的经历、数据、实验、踩过的坑。这是独家，有就优先。
